# 环境配置说明

## 依赖安装

```bash
pip install openai
```

## API Key 配置

### 方式一：环境变量（推荐）

```bash
# 添加到 ~/.zshrc 或 ~/.bashrc
export OPENAI_API_KEY="sk-xxxxxxxx"

# 立即生效
source ~/.zshrc
```

### 方式二：代码中直接设置

```python
from openai import OpenAI

client = OpenAI(api_key="sk-xxxxxxxx")
```

## 模型选择

示例代码使用 `gpt-4o-mini`，成本更低。如需更强能力，可改为 `gpt-4`。

## 运行示例

```bash
# 进入项目目录
cd llm-concepts-explained

# 运行示例
python examples/01_llm_basics.py
python examples/03_function_call.py
python examples/04_agent.py
python examples/06_comparison.py
```

## 常见问题

### Q: 报错 "Incorrect API key provided"
检查 API Key 是否正确设置。

### Q: 想用其他模型
修改代码中的 `model="gpt-4o-mini"` 为其他模型名称。
